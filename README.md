# Körklar – تدريب رخصة القيادة السويدية B

تطبيق ويب تفاعلي للتدرّب على أسئلة رخصة القيادة السويدية B باللغة العربية والسويدية.

يضم التطبيق 1260 سؤالًا موزعة على 18 اختبارًا، مع التدريب حسب المجال، مراجعة الأخطاء، والأسئلة المحفوظة.
